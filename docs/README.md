# GitHub Pages client

Эта папка публикуется через GitHub Pages из ветки `main`.

- `index.html` — входная страница;
- `admin.html` — интерфейс администратора;
- `operator.html` — интерфейс производства;
- `config.js` — публичный адрес Railway API;
- `.nojekyll` — отключает обработку Jekyll.

Секреты и admin token сюда коммитить нельзя.
