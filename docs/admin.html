Снять остатки
Сгенерируйте форму для нужного производства. В форме есть все товары из рабочего каталога. Число, включая 0, означает «товар используется». Знак «−» означает «не используется». После отправки сообщения в WhatsApp вставьте его сюда — остатки сохранятся датой, указанной в форме, а товары с «−» отключатся только на выбранном производстве.

Остатки по производствам

0 — товар используется, но остаток нулевой. «−» — товар на этом производстве не используется. «?» — остаток ещё не получен.

Генератор заявок для GitHub

Выберите производство и день подачи заявки. Все поставщики по графику остаются видимыми; исключённые затемняются с указанием причины.

История заявок и ожидаемые поставки

Вставьте сообщение от производства. Остатки сразу попадут в базу остатков, а заказ создаст заявку поставщику. После подтверждения заявка станет ожидаемой поставкой.

Обновление прайсов / предложений

Сюда загружается UPDATE-файл, который я подготовлю после обработки нового прайса. Он обновляет только каталог поставщиков, цены, связи/аналоги и указанные настройки закупки. Заявки, остатки и история не затираются.
